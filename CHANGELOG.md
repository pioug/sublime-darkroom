## Unreleased

Initial release of Darkroom:

- Pure black editor and interface surfaces with neutral white text.
- Yellow strings, blue functions and keys, iris declarations, peach constants,
  rose language variables, red control flow, and ice blue types and escapes.
- IBM Plex Sans interface typography without changing the code font.
- Rounded active tabs and a compact sidebar with native folder arrows.
- Matching command palette, autocomplete, documentation popups, and search inputs.
- Thin panel borders, subdued scrollbars, and minimap shading.
- An alternate Darkroom P3 color scheme with eight wide-gamut accents on pure black.
