# Darkroom

Darkroom pairs **neutral white text** with *colorful syntax* on pure black.

## The palette

- Soft yellow for strings.
- Neutral white for text and headings.
- Blue for functions and links.
- Iris for keywords and CSS selectors.
- Ice blue for types and attributes.
- Peach for numbers and constants.
- Rose for language variables.
- Soft red for control flow and errors.
- Mint for additions in diffs.

> Comments and secondary text should still be easy to read.

Use `Darkroom.sublime-color-scheme` alongside the matching interface theme.

```python
palette = {"name": "Darkroom", "background": "#000000"}
print(palette["name"])
```

[Sublime Text color scheme reference](https://www.sublimetext.com/docs/color_schemes.html)
